# 中英互译助手

Chrome / Chromium 扩展，版本 2.1.0。适用于任意网页：客服聊天、论坛、商品页、招聘页、邮件、文章与普通页面。

## 整页翻译

在扩展弹窗点“翻译整个页面”，或在网页上右键选“翻译整个页面”。开始后右下角只留一个小圆片（例如 `译 12/63`），点它才展开进度、目标语言、`停止` 与 `还原原文`。

- **不改变网站 UI**：译文直接替换网页自己的文字节点——不新增任何元素、不给网站的元素加属性、也不加覆盖它样式的规则。网站的元素树、链接与加粗、它自己的 CSS 全部原样保留（真机验证：翻译前后整页 DOM 结构指纹逐字符一致）。
- **可见优先**：只先翻进入视口的部分（外扩 200px），往下滚时继续翻；长文章不必等整页跑完，首屏通常几次请求就有译文。
- **可还原**：`还原原文` 把文字写回原值。网站自己在翻译之后改过的文字不会被覆盖；其余位置逐字节复原。
- **只翻该翻的**：代码块（`code`/`pre`）、输入框、按钮、SVG 一律跳过，并遵守网页自己的 `translate="no"` 与 `.notranslate`；目标为中文时跳过本来就是中文的内容。
- **智能混合**：整段只有一个文本节点时就是整段上下文（绝大多数正文），被链接/加粗拆成多个节点时按节点分别翻——换来的是内联格式与链接完好。术语表对整页生效，同一个术语全页统一。
- **动态内容**：无限滚动或单页应用新插入的内容会被登记，滚到可见处再翻。

整页翻译**只走 AI 模式**，不会静默回退到免费接口（未配置 Key 会直接提示）。代价按页长线性增长：一页 3 万字符大约二十次请求、几十秒；单页总量上限 20 万字符，达到上限会在小圆片里提示。

两点如实说明：译文长短不同仍会带来轻微重排，这是任何原地翻译都免不了的——但不会再插入译文框、页面也不会被撑长一倍；网站若在翻译之后重新渲染同一段文字，那一段不会自动重译（新插入的段落会）。

## 写作与阅读

- **译文预览与还原**：在网页输入框里点击“译”或按 `Ctrl+Enter`，对照原文和可编辑译文，再点“确认替换”。扩展不会自动发送消息。替换后可点面板里的“还原原文”，或输入框旁的“还”。输入框已被继续编辑时会阻止覆盖和还原。
- **结合上下文写回复**：选中对方的话，右键选择“结合选中文字写回复”；输入自己的中文大意，选择简短、礼貌或强硬语气，再生成回复。也可从扩展弹窗打开并粘贴上下文。
- **个人术语表**：在扩展弹窗展开“个人术语表”，每行填写 `中文 = English` 并保存。例如 `续费价 = renewal price`、`VPS = VPS`。中英互译按方向应用，Google 与 AI 翻译都支持，整页翻译同样生效。最多 100 条、12000 字符，仅保存在本机。
- **发送前查漏**：译文预览自动提示数字、币种、单位、计费周期和否定词的字面差异。点击“AI 查漏”进一步核对含义、遗漏及新增承诺。也可手动粘贴原文和译文进行检查；修改内容后旧检查失效。
- **关键信息提取**：选中网页内容，右键选择“提取关键信息”，或点击扩展弹窗中的同名按钮。要点由内容自行决定（3–8 项），不绑定任何行业或站点；每个要点都必须附**逐字原文引用**，对不上原文的要点不会显示。想聚焦时在“关注点”里填写，例如 `价格、续期、是否支持退款`，扩展会为每一项都给出结果，原文里没有依据的标为“未说明”。

写回复、AI 查漏、关键信息提取和整页翻译需要先在设置中启用 AI 模式并配置 API Key。生成内容需要自行核对；基础检查和 AI 查漏都不是正确性保证。


## 场景判断

扩展不针对具体网站做适配：场景由 `og:type`、JSON-LD `@type`、URL 路径词和页面文本标记推断，结果为即时聊天、商品/报价、招聘、论坛帖、文章/文档、邮件或通用网页之一，只用于给模型一句语气与场景提示。面板里会显示当前判断结果，判断不适用时以输入框里的原文和上下文为准。跨进程只传这几种枚举值，页面文本不会进入提示词。

翻译最多 5000 字符，回复上下文最多 8000 字符，关键信息提取最多 20000 字符；整页翻译按块分批（每批约 1500 字符、最多 12 段），单页最多 20 万字符。超长内容请手动分段，扩展不会静默截断翻译。术语按字面最长匹配，英文匹配词边界；翻译服务破坏术语占位符时会报警并保留原文。

如需把回复直接写入网页，请先点击网页输入框，再打开写作面板；没有绑定输入框时可复制结果。页面刷新后原文还原记录不保留。

AI 写作请求只发送面板中显示的输入内容、关注点及个人术语；整页翻译发送网页正文分块；AI 操作模式会另外读取页面状态。标准密码框及能识别的验证码、银行卡输入框会被排除，未标注的自定义敏感字段无法保证识别。

## 开发与验证

```sh
npm ci
npm test
```

测试使用模拟服务，不需要真实 API Key。回归检查覆盖翻译预览、还原与编辑冲突、伪造事件拦截、敏感字段、截图切页保护、术语双向匹配、上下文回复、查漏引用、通用要点提取与关注点缺失、无法对照原文的要点被丢弃、场景白名单不会把页面文本带进提示词，以及整页翻译的分批协议、跳过规则（含 `translate="no"`）、可见优先、行内空白不被粘连、翻译前后 DOM 结构零变化、网站自己改过的文字不被还原覆盖，以及停止/继续与逐字节还原。

在 `chrome://extensions` 开启开发者模式，加载本目录。更新文件后重新加载扩展并刷新网页。
