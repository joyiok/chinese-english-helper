## 整页翻译

在扩展弹窗点「翻译整个页面」，或在网页上右键选择。开始后右下角只留一个小圆片（例如 `译 12/63`），点它才展开进度、目标语言、`停止` 与 `还原原文`。

- **不改变网站 UI** — 译文直接替换网页自己的文字节点：不新增元素、不加属性、不覆盖样式。真机验证：翻译前后整页 DOM 结构指纹逐字符一致。
- **可见优先** — 只先翻进入视口的部分（外扩 200px），滚动时继续翻；长文章首屏几次请求就有译文。
- **可还原** — `还原原文` 逐字节复原；网站自己在翻译后改过的文字不会被覆盖。
- **只翻该翻的** — 代码块、输入框、按钮、SVG 跳过；遵守网页自己的 `translate="no"` 与 `.notranslate`；目标为中文时跳过本来就是中文的内容。
- **智能混合** — 单一文本节点的段落整段翻（上下文最全），被链接/加粗拆开的段落按节点翻（格式与链接完好）。术语表全页生效。
- **动态内容** — 无限滚动、单页应用新插入的内容会登记，滚到可见处再翻。
- **只走 AI** — 未配置 Key 会直接提示，绝不静默回退到免费接口。

> **两点如实说明**：译文长短不同仍会带来轻微重排——任何原地翻译都免不了；网站若在翻译之后重新渲染同一段文字，那一段不会自动重译（新插入的段落会）。

代价按页长线性增长：一页 3 万字符约二十次请求、几十秒；单页上限 20 万字符，达到上限会在小圆片里提示。

## 写作与阅读

- **译文预览与还原** — 在网页输入框里点「译」或按 `Ctrl+Enter`，对照原文和可编辑译文，确认后替换。不会自动发送消息；替换后可还原，输入框被继续编辑时会阻止覆盖和还原。
- **结合上下文写回复** — 选中对方的话右键「结合选中文字写回复」，输入中文大意，选简短/礼貌/强硬语气。也可从弹窗打开并粘贴上下文。
- **个人术语表** — 每行 `中文 = English`，中英互译按方向应用（如 `续费价 = renewal price`、`VPS = VPS`）。最多 100 条、12000 字符，仅存本机。
- **发送前查漏** — 译文预览自动提示数字、币种、单位、计费周期和否定词的字面差异；「AI 查漏」进一步核对含义、遗漏及新增承诺。都不是正确性保证。
- **关键信息提取** — 要点由内容自行决定（3–8 项），每个要点都附**逐字原文引用**，对不上原文的要点不显示。可在「关注点」里聚焦，例如 `价格、续期、是否支持退款`；原文没有依据的项标为「未说明」。

| 内容类型 | 上限 |
| --- | --- |
| 单次翻译 | 5000 字符 |
| 回复上下文 | 8000 字符 |
| 关键信息提取 | 20000 字符 |
| 整页翻译 | 每批约 1500 字符 × 12 段，单页 20 万字符 |

超长内容请手动分段，扩展不会静默截断。术语按字面最长匹配，英文匹配词边界；翻译服务破坏术语占位符时会报警并保留原文。想直接把回复写入网页，先点击网页输入框再打开写作面板。

## 场景判断

场景由 `og:type`、JSON-LD `@type`、URL 路径词和页面文本标记推断，结果为即时聊天、商品/报价、招聘、论坛帖、文章/文档、邮件或通用网页之一，只用于给模型一句语气与场景提示。跨进程只传枚举值，**页面文本不会进入提示词**。

## 在线更新

扩展以 GitHub 仓库 main 分支的 `manifest.json` 为版本事实源，每 12 小时自动检查一次（定时器、浏览器启动与打开弹窗都会触发，统一节流）。发现新版本时发一条系统通知，**同一版本只提醒一次**；点通知或弹窗里的「下载更新包」获取 zip。弹窗里可随时手动检查，也可关闭自动检查。

扩展不能改写自身目录（浏览器扩展的通用限制），更新需手动完成，三种方式任选：

1. **zip**：下载解压，覆盖本地扩展目录，到 `chrome://extensions` 重新加载；
2. **git**：仓库目录里 `git pull`，同样重新加载；
3. 检查只请求仓库的 `manifest.json`（`raw.githubusercontent.com`），不发送任何本机数据或配置——但 GitHub 能看到来源 IP。

## 安装

```sh
git clone https://github.com/joyiok/chinese-english-helper.git
```

或从 GitHub 页面 **Code → Download ZIP** 下载解压。然后：

1. 打开 `chrome://extensions`，开启右上角**开发者模式**；
2. 「加载已解压的扩展程序」，选择本目录；
3. 可选：点扩展图标 → 翻译引擎 → **AI 大模型** → 选服务商 → 填 API Key。

更新文件后在 `chrome://extensions` 点重新加载，并刷新已打开的网页。

## 隐私

- AI 写作请求只发送**面板中显示的**输入内容、关注点及个人术语；整页翻译发送网页正文分块；AI 操作模式会另外读取页面状态。
- 标准密码框及能识别的验证码、银行卡输入框会被排除；未标注的自定义敏感字段无法保证识别。
- 更新检查只请求仓库的 `manifest.json`，不携带任何用户数据。
- 术语表与全部设置仅存本机；扩展无后端、无遥测、无账号。
- 生成内容需自行核对；基础检查和 AI 查漏都不是正确性保证。

```sh

```

测试使用模拟服务，不需要真实 API Key，共 **355 条断言**。回归覆盖：

- 翻译预览、还原与编辑冲突、伪造事件拦截、敏感字段排除、截图切页保护；
- 术语双向匹配、上下文回复、查漏引用、要点提取与关注点缺失、无法对照原文的要点被丢弃；
- 场景白名单不会把页面文本带进提示词；
- 整页翻译的分批协议、跳过规则（含 `translate="no"`）、可见优先、行内空白不粘连、翻译前后 DOM 结构零变化、网站自改文字不被还原覆盖、停止/继续与逐字节还原；
- 在线更新的版本比较、节流缓存、同版本通知去重、失败回退缓存、设置开关与弹窗自动检查。
